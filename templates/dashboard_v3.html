About Federated Learning

Federated Learning is a distributed machine learning paradigm that enables model training across multiple decentralized devices while preserving data privacy. Instead of centralizing all data in one location, each node trains a local model on its own data and only shares model updates with a central server.

Key Features of This Dashboard:

  • ✓ Interactive node configuration and simulation
  • ✓ Real-time visualization of federated learning dynamics
  • ✓ Multi-strategy comparison (Static, Centralized, Federated, Energy-Aware)
  • ✓ Fairness and sustainability metrics
  • ✓ Comprehensive logging and export capabilities
  • ✓ Research-grade reproducibility with seeded randomness
