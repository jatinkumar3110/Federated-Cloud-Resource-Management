ℹ️ About Federated Learning

Federated Learning is a distributed machine learning approach that trains models across multiple decentralized devices or clients while keeping data local. Instead of centralizing data, each client trains on its own data and only shares model updates with a central server. The server then aggregates these updates using algorithms like FedAvg (Federated Averaging) to create a global model.

Key Benefits: 🔒 Privacy preservation • 🌍 Distributed training • ⚡ Reduced bandwidth • 🎯 Better generalization with heterogeneous data
